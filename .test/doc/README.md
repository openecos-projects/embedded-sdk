# Test Documentation Index

This directory stores planning and design documents for SDK automated testing.

The AI-readable structure summary is maintained in:

- `doc-structure.yaml`

Language guideline:

- Use English for directory names, IDs, metadata, and machine-readable summaries.
- Chinese is acceptable for detailed design documents when it is more efficient for the team.
- Prefer stable IDs and explicit paths so AI agents and scripts can locate documents reliably.
